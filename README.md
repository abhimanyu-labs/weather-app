# Weather App

A lightweight weather app built to practice DOM manipulation, asynchronous JavaScript (`async/await`), and working with third-party APIs.

## Features
- Search weather by city name worldwide
- Real-time temperature, humidity, and wind speed metrics
- Automatic conversion of WMO weather codes into readable conditions
- Error handling for invalid city names and network issues

## Tech Stack
- **HTML5 & CSS3**
- **Vanilla JavaScript** (ES6+)
- **Open-Meteo API** (Geocoding & Forecast endpoints)

## What I Learned / Practiced
- Handling form submission events and preventing default page reloads (`preventDefault`)
- Fetching and parsing asynchronous JSON data using `fetch` and `async/await`
- Chaining sequential API calls (resolving city coordinates first, then requesting weather data)
- Managing dynamic UI states (loading indicators, error alerts, data rendering)

## How to Run
Open `index.html` in any browser or launch it using VS Code Live Server.
